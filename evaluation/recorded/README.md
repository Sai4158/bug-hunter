# Saved evaluation evidence

These are unchanged October 5, 2026 runs recorded on the original Windows/CPU
development machine, not a new benchmark on your computer. They include baseline
controls, rejected responses, unsuccessful fixes, and successful fixes. Nothing was
rewritten to improve an outcome. `SHA256.json` records the original file bytes.

The Evaluation page labels these as saved samples. A JSON companion takes precedence
over its CSV; the older CSV-only run is labeled as limited evidence. Human review
remains Unreviewed where no explicit judgement was supplied. A pytest-verified fix
does not establish that its explanation is correct or that all bugs were detected.

`smoke/` contains genuine browser text captures, not reconstructed API responses.
New runs go to the ignored `evaluation/results/` directory. New human judgements go
to the ignored `evaluation/reviews/` directory. Neither overwrites these snapshots.
